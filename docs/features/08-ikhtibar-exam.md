# 8. Ikhtibar - Exam — IKH

> **Product spec:** [Al-Mahir-SDD.md](../Al-Mahir-SDD.md) → "Epic 8: Ikhtibar - Exam". That file is the canonical product requirement; this doc is the agent build brief.
> **Rules:** [AGENTS.md](../../AGENTS.md) — architecture, modules, MVI, stack, localization (do not restate them here).

**Priority:** SHOULD · **Primary modules:** :presentation, :domain, :data (audio/AI feature → MAY get its own layered module set per AGENTS §2)

## Purpose
Formal assessment module that generates customized test prompts and scores recited answers to evaluate memorization retention.

## Must-know constraints
- Exam starts a **clean state and disables inline hints** (IKH-01) — the FBK hint/reveal actions ([[09-feedback-bar]]) MUST be suppressed during an exam; record the start timestamp.
- Questions are **auto-generated by the backend, randomized per chosen strategy** (Spot-check / Complete-from-memory / Start-to-finish), so every attempt is unique (IKH-03/04).
- Prompt playback plays only the **first few words then stops** and asks the user to continue from memory (IKH-05).
- **Mic pre-prompt before the native OS permission dialog** (SEC-03); on-device **VAD** + **hybrid ASR** (AUD-04); live scoring feeds the verification system (IKH-06) with **< 1.0s** feedback (PRF-01).
- **Decoupled scoring** (ACC-04); results break mistakes down by **tajwid / memorization / tashkeel** using the shared taxonomy (SDD §4 ProtoBuf `almahir.v1`) — IKH-08.
- Auto-complete stops mic + timer, computes final score, and generates the report (IKH-07); results show Score, Accuracy %, mistake breakdown, Duration, Grade.
- Mistake review highlights errors on the script with **color + icon + text**, tappable for detail (IKH-09, A11Y-01).
- Export as **PDF/image** (student name, date, score, mistakes) and share via the **native share sheet** (IKH-10/11).
- **Recover interruptions**: auto-save exam state on call/minimize and resume the active question (IKH-13, AVL-03).
- Exam generation + scoring are cloud-dependent → **disable gracefully offline** with guidance (OFF-08, AI-12, AVL-02). Localized (ar+en), RTL-aware, locale-aware numbers/dates (LOC-04).

## Design system (`:designsystem`)
- Config: **VerseRangePicker** (see [[06-taahud-live-correction]]); strategy selector via `DayTabRow`/`TabSelector`.
- Prompt playback: reuse **AudioPlayerBar** (see [[05-listen-mode]]) in prompt-only mode.
- Recording: **RecordingIndicator**; shared **FeedbackBar** with **hints disabled** (see [[09-feedback-bar]]).
- Results: **needs new :designsystem component: ScoreCard / GradeBadge**; **MistakeBreakdownChart** (see [[06-taahud-live-correction]]); `SectionedCard` for metric rows.
- Review: **MistakeHighlight** over the script + `AppBottomSheet` detail panel.
- Export/share: render to PDF/image via Android `PdfDocument`/Canvas (**needs new :designsystem component: ExamResultSheet** as the exportable layout); `IconButton` triggers the native `Intent` share sheet.
- History: `SectionedCard` list; `EmptyDataScreen` when no past exams (IKH-12).
- Processing/offline: `StatusOverlay` (`Loading`/`Success`/`Error`); `NetworkErrorScreen` / disabled state with guidance when generation/scoring is offline.
- `BackTitleTopBar`; all tokens via `Theme.*`; RTL-aware.

## Data, stack & offline
- `data`: backend (Ktor/gRPC) generates questions (IKH-04); mic capture + VAD + light ASR + **cloud scoring over shared ProtoBuf** (`AyahFeedback`/`EvaluationMistake`/`SessionLog`, ARC-02/03); Room persists in-progress exam state (recovery), results, and previous exams. PDF/image export is local; share via `Intent`.
- Offline: exam generation and scoring require the network → gracefully disabled (OFF-08); previously scored exams read from Room offline (OFF-03). Queue history sync ([[17-offline-sync]]). No DTO/Room/gRPC leakage to UI.
